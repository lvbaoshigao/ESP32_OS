## 1. PKI（Package Installer）软件包管理程序更新

PKI是内核级软件包管理工具，用法如下：

```
PKI -help
PKI -i <package.espapp>
PKI -r <packagename>
PKI -m <file_directory>
```

### 参数说明：
- `-help`：显示帮助信息
- `-i`：安装指定的 `.espapp` 软件包
- `-r`：按包名移除已安装的软件包
- `-m`：将指定目录打包成 `.espapp` 格式

### 实现要求：
- `.espapp` 文件为自定义打包格式，包含自描述头（包名、版本、入口函数偏移、依赖列表、文件清单等）
- 安装时解析包头，将文件释放到 `/app/<包名>/` 目录，并注册到系统命令表
- 移除时删除对应目录并清理命令表条目
- 打包时递归扫描目录，生成包头和文件数据段

## 2. 用户管理

增加 `user` 命令，用于管理系统用户账户。

### 用法：
```
user -add <username>
user -del <username>
user -per <username> <root|user>
```

### 参数说明：
- `-add`：创建新用户，默认权限为 `user`
- `-del`：删除指定用户及其主目录
- `-per`：修改用户权限级别（`root` 为超级用户，`user` 为普通用户）

### 实现要求：
- 用户数据存储在 `/system/passwd` 文件中，格式为 `用户名:权限级别`
- 创建用户时在 `/user/<username>/` 下自动生成用户主目录，包含 `desktop` 和 `download` 子目录
- 删除用户时清理其所有文件和目录
- 权限检查：`root` 可执行所有命令，`user` 受限（如无法安装/移除软件包）

## 3. 管道标识符传递信息

增加管道（pipe）机制，支持命令间数据传递。

### 语法：
```
command1 | command2
```

### 实现要求：
- 使用内核管道缓冲区（如环形缓冲区）实现进程间通信
- Shell解析 `|` 符号后创建管道，将 `command1` 的标准输出重定向到管道写端，`command2` 的标准输入重定向到管道读端
- 支持多个管道串联：`cmd1 | cmd2 | cmd3`
- 管道缓冲区大小可配置（默认4KB）

## 4. 增强错误处理

完善系统级错误处理机制。

### 实现要求：
- 定义统一错误码体系（参考POSIX errno），如 `EACCES`、`ENOENT`、`ENOMEM` 等
- 每个系统调用返回明确的错误码
- Shell在命令执行失败时显示对应错误信息，例如：
  - `PKI: 文件未找到 (ENOENT)`
  - `user: 权限不足 (EACCES)`
- 内核panic时输出详细寄存器状态和调用栈回溯

## 6. 增加ps命令

用法与Linux一致：

```
ps        # 显示当前终端的所有进程
ps -a     # 显示所有进程
ps -l     # 长格式显示，包含PID、PPID、状态、优先级、内存占用、命令名
```

### 实现要求：
- 内核维护进程控制块（PCB）链表，包含每个进程的PID、状态、优先级、内存使用等信息
- `ps` 通过系统调用遍历PCB链表并格式化输出
