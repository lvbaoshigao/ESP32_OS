# ESP32-C3 用户程序开发规范（用户工具）

## 1. 总体目标
开发一个符合 **RISC-V 汇编规范** 的 ESP32-C3 用户程序，该程序**不依赖 IDF**，运行于已完成的引导程序与内核之上。

> **重要前提**  
> - 若内核或引导程序尚未完成开发，**严禁**阅读或遵循本文档，更**严禁**执行本文档的任何操作。  
> - 文档 `doc.MD` 始终拥有最高优先级。

---

## 2. 基本要求
- 根据已有内核源码，开发一个用户工具程序。
- 该程序应在内核启动之初作为**最主要的进程**启动（若内核代码不足以实现此要求，允许进行必要修改，但**严禁进行破坏性更改**）。
- 程序启动后默认进入 **Bash 风格命令行环境**，提示符格式为：
  ```
  username/device_name:
  ```

---

## 3. 与内核的交互
- 用户程序负责与内核 API 交互。
- 若所需 API 不存在，允许进行开发，但**严禁进行破坏性更改**。

---

## 4. 内置命令规范

### 4.1 通用规则
- 所有命令后跟 `-help` 参数时，应输出该命令的详细帮助信息。
- 默认命令参数分隔符为**空白符**（空格/制表符），可通过 `chdiv` 命令更改。

### 4.2 命令列表

| 命令 | 功能描述 | 用法示例 |
|------|----------|----------|
| `help` | 输出所有命令的帮助信息 | `help` |
| `ls` | 列出当前目录下的用户文件 | `ls` |
| `mkdir` | 在当前目录下新建文件夹 | `mkdir new`（创建名为 `new` 的文件夹） |
| `com` | 查看端口连接情况 | `com` |
| `net` | 查看网络连接情况 | `net` |
| `newfile` | 在当前目录下新建文件 | `newfile new.md`（创建 `new.md` 文件） |
| `pwd` | 输出当前工作目录的绝对路径 | `pwd` |
| `rename` | 重命名文件或目录 | `rename oldname newname` |
| `cd` | 切换当前工作目录 | `cd /path/to/dir` |
| `disk` | 查看磁盘信息 | `disk -free`（查看可用空间）<br>`disk -parted`（进行分区操作）<br>`disk -part`（查看当前分区情况） |
| `device` | 查看设备的基本信息 | `device` |
| `chdiv` | 更改命令参数分隔符 | `chdiv "/"`（将分隔符改为 `/`，之后所有命令参数间使用 `/`，如 `ls/-help`） |
| `wifi` | 查看当前 Wi‑Fi 基本信息（输出 SSID 等） | `wifi`<br>`wifi -changepasswd`（更改 Wi‑Fi 密码）<br>`wifi -on`（开启 Wi‑Fi）<br>`wifi -off`（关闭 Wi‑Fi，关闭后切换为串口输出） |
| `reboot` | 重启 ESP 设备 | `reboot` |

---

## 5. 开发限制
- 不得引入 ESP‑IDF 框架。
- 任何对内核源码的修改必须是非破坏性的，且仅用于满足程序启动或 API 交互需求。
- 所有命令需在 Bash 环境中正确解析，支持通过 `chdiv` 更改分隔符。

---

## 6. 优先级说明
- 本文档为开发规范，具体实现细节若与 `doc.MD` 冲突，以 **`doc.MD`** 为准。
